# ADR-003 · Claude Code 联动：只读元数据 + 定期扫描 + 独立功能面板

- **状态**：已接受
- **日期**：2026-10-22
- **决策者**：项目维护者

## 背景

桌宠需要与 VSCode / Claude Code 更紧密：知道近期有几个项目、最后在哪里工作，并能在之后通过对话选项打开 VSCode。需要在不读取聊天内容、不引入外部插件执行权限的前提下实现，并预留功能扩展架构。

## 选项

| 维度     | 选项                            | 取舍                                           |
| -------- | ------------------------------- | ---------------------------------------------- |
| 数据来源 | 只读扫描 / 用户级钩子 / 两者    | 扫描不改配置、覆盖历史；钩子实时但需改全局设置 |
| 数据范围 | 元数据 / 会话摘要 / 完整内容    | 元数据隐私最好；摘要与内容风险高               |
| 面板形态 | 托盘原生菜单 / 独立功能面板     | 面板可承载列表、插件页与复杂 UI                |
| 插件架构 | 编译期模块 / 运行时加载外部代码 | 编译期安全；运行时扩展强但风险高               |

## 决策

采用以下组合：
1. **只读元数据**：项目路径、最后活跃时间、会话数、最近会话 id；不读对话内容、prompt、代码。
2. **定期扫描**：扫描 `~/.claude/projects/*`；默认 5 分钟一次，功能面板打开时立即刷新；实时钩子作为未来可选项。
3. **独立功能面板**：普通窗口，从宠物右键打开；项目下展示最近 5 个会话，可先开文件夹再通过 `vscode://anthropic.claude-code/open?session=<id>` 打开对应对话；不做托盘入口。
4. **编译期模块 + 预留运行时接口**：功能以代码模块注册；定义 manifest/加载边界，但本版本不加载外部代码。
5. **项目显示名**：读取最新会话元数据中的 `cwd` 字段，取文件夹名；失败时回退到目录名。
6. **主动台词**：默认低频率；可在设置中调整或关闭（关闭 / 低 10% / 中 25% / 高 40%）；每分钟最多 1 次、每小时最多 3 次。

## 后果

- 正面：桌宠能理解工作现场；不触碰对话内容；扩展架构清晰；未来可加实时钩子与 AI 上下文。
- 负面：需要新增功能面板窗口与扫描服务；项目名解析依赖会话元数据格式，格式变化时需兼容。
- 后续：若启用实时钩子，需单独 ADR 并获用户明确授权；AI 聊天若引用项目信息，只使用项目名/时间等元数据，不发送对话内容。
