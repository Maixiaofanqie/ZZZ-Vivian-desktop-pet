# ADR-006 · v1.0 非商业公开发布与安装包策略

- **状态**：已接受
- **日期**：2026-10-26
- **决策者**：项目维护者

## 背景

v1.0 需要产出 NSIS 安装包、应用图标与用户文档。角色形象素材（7 张静态图）此前仅标注为「仅本机个人使用、不公开分发」；后来获得素材作者的非商业使用许可，因此 v1.0 可以按非商业方式公开发布，但仍需保留署名、非商用说明，不得售卖或用于商业推广。

代码仍为 MIT；角色形象素材适用作者的非商业许可，二者分开声明。源码仓库固定为「无角色美术」版本，角色美术只在官方非商业发行包中提供。

## 选项

| 选项                       | 优点                               | 缺点                                                     |
| -------------------------- | ---------------------------------- | -------------------------------------------------------- |
| A 仅本机个人使用           | 授权边界最简单                     | 无法分享；分发目标落空                                   |
| B 非商业公开发布（本决定） | 符合作者非商用许可；可让更多人使用 | 需要署名、非商用声明、SmartScreen 说明与更完整的用户文档 |
| C 商业发布                 | 可能覆盖成本                       | 超出作者许可与项目非商业定位，不做                       |
| D 暂停发布等进一步授权     | 最保守                             | 阻塞 v1.0 收尾                                           |

## 决策

**v1.0 以非商业方式公开发布。**
- 发布性质：免费、非商业；不得售卖、内购、广告变现或用于商业推广。
- 素材署名：安装包「关于」、用户手册与 `assets/CREDITS.md` 保留角色素材的非商用授权说明；作者署名为 **抖音@星穹列车星某**。
- 代码与素材许可分离：代码、原创文档与原创中性图标为 MIT；角色形象及其派生图标适用作者的非商业许可，不适用 MIT，不进入源码仓库。
- 源码仓库：固定为「无角色美术」，使用中性图标；没有角色图时宠物窗口留空。角色美术由维护者在本机 overlay 构建后手动上传 Release，不进入公开仓库、CI 或 release workflow。
- 安装包：NSIS、按用户安装、不要求管理员权限、可选安装目录、桌面与开始菜单快捷方式；不购买代码签名证书，未签名导致的 SmartScreen 提示写入用户手册。
- 卸载：`deleteAppDataOnUninstall: true`，卸载删除程序、快捷方式、自启项与 `%APPDATA%` 用户数据；用户手册显著警告并提供导出备份方法。
- 测试与发布：测试和发布使用同一个 NSIS 产物，记录 SHA-256 与构建提交；本机安装测试前备份用户数据，测试后恢复。
- 更新检查：v1.0 不做自动更新检查；设置页「关于」显示版本、素材授权与非商用说明。
- 发布动作：构建、测试与文档完成后，由维护者手动上传；不自动发布。

## 后果

- 正面：v1.0 可以合法地以非商业方式分享；安装包、图标与文档口径统一。
- 负面：未签名安装包会触发 SmartScreen；卸载删除数据需要用户先备份；角色素材作者已具名（抖音@星穹列车星某），但授权范围仍限于非商业发布。
- 后续：若需要商业发布或代码签名，重新评估授权与成本，另写 ADR；若公开源码仓库，保持「无角色美术」边界，不得把未授权素材放入公开仓库或 CI。
