# 薇薇安桌宠 · 用户手册

> 版本：v1.0.0
> 适用系统：Windows 11（x64）
> 性质：非商业同人作品，免费分享；不得售卖或用于商业推广。

## 1. 安装

1. 从 [Releases](https://github.com/Maixiaofanqie/ZZZ-Vivian-desktop-pet/releases) 下载 `Vivian-Desk-Pet-1.0.0-Setup.exe`。
2. 如果 Windows 弹出「已保护你的电脑」提示：点击「更多信息」→「仍要运行」。安装包没有购买代码签名证书，这是正常提示；不要关闭 SmartScreen 或修改系统安全设置。
3. 选择安装目录（默认按当前用户安装，不需要管理员权限），按向导完成安装。
4. 安装完成后，桌面和开始菜单会出现「Vivian Desk Pet」快捷方式。勾选「开机自启」后，登录 Windows 时会自动启动。

首次启动后，薇薇安会出现在主屏右下角、工作区底部。她没有任务栏按钮，常驻托盘。

> **源码构建说明**：从源码仓库构建的版本不包含角色美术，宠物窗口为空（透明、不拦截点击）；设置页会提示如何添加本地形象。完整角色形象只在官方 Release 安装包中提供。

## 2. 基本操作

| 操作         | 效果                                                           |
| ------------ | -------------------------------------------------------------- |
| 单击         | 弹出一句台词，并记录一次互动                                   |
| 双击         | 在「双击切换形象」开启且有多个形象时循环切换；固定模式下不切换 |
| 拖拽         | 移动位置；松手后会落到当前屏幕工作区底部                       |
| 悬停         | 轻微放大与提亮，不弹台词                                       |
| 右键         | 打开菜单：番茄钟（若开启）→ 功能面板 → 设置 → 隐藏 → 退出      |
| 托盘图标单击 | 显示 / 隐藏薇薇安                                              |
| 托盘右键     | 显示/隐藏、重置位置、设置、番茄钟、退出                        |

气泡会逐字淡入；淡入过程中再点一下宠物可以立即显示全文。快速连点时，新台词会替换旧台词，不会叠加。

## 3. 第一次使用建议

1. 右键宠物 →「设置」，先确认形象与「开机自启」。
2. 在「模块」里按需开启功能。默认开启：预知式提醒、整点报时、天气；番茄钟与 Claude Code 联动默认关闭，需要时手动开启。
3. 天气模块开启后，在设置里搜索城市并选择正确候选；不配置城市时天气页会显示引导。
4. 右键宠物 →「功能面板」，可以查看 Claude Code 最近项目、天气与日程 · 待办。
5. 在「数据备份」里导出一次备份，留作换机或重装前的保险。

## 4. 设置说明

### 4.1 形象与表现

- **双击切换形象**：开启后双击宠物在可用的内置形象间循环；关闭后固定显示当前选中的形象。源码构建没有形象图时，该开关会禁用，并显示占位预览。
- **待机微动效**：呼吸与轻微摇摆，默认开启；关闭后完全静态。
- **定时主动问候**：默认关闭；开启后每 30–60 分钟轻声说一句，隐藏、拖拽或已有气泡时跳过。

### 4.2 模块

模块关闭后不再占用定时器，也不会出现在功能面板中。各模块的设置项：
- **番茄钟**：专注 5–60 分钟、休息 1–30 分钟；通过托盘或右键菜单开始、暂停、继续、重置。跨重启恢复，错过的完成提示会在下次启动补发。
- **预知式提醒**：添加一次性提醒；到点由薇薇安用「预知」的方式提示。关闭期间错过的提醒会在下次启动补发。
- **整点报时**：全天 24 小时整点轻声报时；23:00–08:00 是否报时由「夜间互动」中的子开关控制。
- **Claude Code 联动**：默认关闭，开启后只读查看本机 Claude Code 项目与最近会话；可设置项目范围（7 天 / 30 天 / 全部）与主动提及频率（关闭 / 低 10% / 中 25% / 高 40%）。只读取元数据，不读取对话内容、prompt 或代码。
- **天气**：搜索城市并选择候选；天气数据来自 Open-Meteo，免 Key。

### 4.3 作息与夜间

- **久坐提醒**：连续在电脑前 60 分钟时提醒起身；休息 5 分钟重置。
- **彩蛋**：纪念日与互动里程碑的专属台词。
- **夜间互动**：23:00–08:00 的总开关；关闭后夜间不主动问候、不报时、不催睡。
- **深夜催睡**：23:30–05:00 轻声提醒休息，一晚最多两次。

### 4.4 数据

- **导出**：把设置、共处记录、记忆与模块数据保存为一个 JSON 文件。
- **导入**：校验后整体替换当前数据；导入前会自动备份当前数据。不同安装标识（appId）导出的旧备份也可以导入。
- **重置共处记录**：清空首次见面、互动次数、活跃日与记忆里程碑；不会删除日志。
- **开机自启**：只在安装版生效；开发版不会写入系统自启项。

### 4.5 关于

设置页底部显示当前版本、非商业性质与数据说明。v1.0 不内置自动更新检查；后续版本请从发布页手动下载安装包。

## 5. 功能面板

右键宠物 →「功能面板」。左侧列表由已启用的模块决定：
- **Claude Code · 最近项目**：最近活跃项目、最后活跃时间、会话数；「刷新」重新扫描；「打开」先打开项目文件夹，再打开对应 Claude Code 对话。若对话没有打开，请确认已安装 Claude Code VSCode 扩展，或在终端运行 `claude --resume <会话 id>`。
- **天气**：当前温度、体感、天气现象、最高/最低、降水概率、湿度、风速与更新时间；「刷新」有 1 分钟限频。
- **日程 · 待办**：可按「未完成 / 已完成」筛选；点圆形勾选标记完成，再点取消；完成项会降低透明度并划线。到点提醒后该事项会从列表归档，不计入「已完成」。可按日期、时间与内容快捷添加，或删除。与提醒模块共用数据。

功能面板只读取本机元数据，不读取对话内容、不发送网络请求（天气页除外，仅访问 Open-Meteo）。

## 6. 数据、日志与备份

数据目录：`%APPDATA%\vivian-desktop-pet\`

| 文件 / 目录      | 内容                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| `settings.json`  | 用户设置、模块开关、自启等                                                               |
| `profile.json`   | 共处记录与记忆                                                                           |
| `modules.json`   | 模块运行时数据（天气快照、提醒、番茄钟等）                                               |
| `state.json`     | 窗口位置等易失信息                                                                       |
| `run-state.json` | 上次运行是否正常退出                                                                     |
| `logs\`          | 主日志 `main-YYYY-MM-DD.log`（保留 7 天）与崩溃日志 `crash-YYYY-MM-DD.log`（保留 14 天） |
| `backup-*`       | 导入前自动生成的本地备份                                                                 |

日志用于排查启动、窗口、模块与崩溃问题，不记录 API Key、完整 Claude Code 项目路径、对话内容或用户输入文本。

## 7. 卸载

**注意：卸载会删除 `%APPDATA%\vivian-desktop-pet\` 下的设置、共处记录、记忆、模块数据与日志，无法恢复。** 卸载前请先在设置页「数据备份」导出备份。
1. 打开 Windows「设置」→「应用」→ 已安装的应用，找到「Vivian Desk Pet」→「卸载」。
2. 或在开始菜单找到「Vivian Desk Pet」文件夹中的卸载快捷方式。
3. 按向导完成卸载；程序文件、桌面/开始菜单快捷方式、开机自启项与用户数据会一并清理。

## 8. 常见问题

**Q：启动后看不到薇薇安。**
A：先看系统托盘是否有伞形图标；单击托盘图标显示。如果她在屏幕外，右键托盘 →「重置位置」。

**Q：源码构建启动后宠物窗口是空的。**
A：这是预期行为。源码仓库不包含角色美术；把 7 张图放入 `assets/characters/<set>/` 后重新构建，或使用官方 Release。完整角色形象只在官方 Release 安装包中提供。

**Q：开机自启没有生效。**
A：确认使用的是安装版而不是开发版；在设置里关闭再开启一次「开机自启」；检查 Windows「任务管理器」→「启动应用」中是否被禁用。

**Q：天气页没有数据。**
A：在设置中搜索并选择城市；确认网络可用；点「刷新」重试。天气请求只访问 Open-Meteo。

**Q：Claude Code 面板是空的。**
A：确认本机 `~/.claude/projects` 下有 Claude Code 会话；点「刷新」。面板只读元数据，不会读取对话内容。

**Q：番茄钟/提醒没有响。**
A：确认对应模块已开启；提醒到点时如果宠物被隐藏或正在拖拽，会等下一次可展示时机；错过的提醒会在下次启动补发。

**Q：CPU 占用偏高。**
A：在设置中关闭「待机微动效」；确认没有同时运行多个桌宠实例（应用为单实例，重复启动只会显示已有宠物）。

**Q：安装时提示「Windows 已保护你的电脑」。**
A：安装包未签名。点击「更多信息」→「仍要运行」即可；不要在系统中关闭 SmartScreen。

**Q：日志在哪里？**
A：`%APPDATA%\vivian-desktop-pet\logs\`。反馈问题时可附上最近一天的 `main-*.log` 与 `crash-*.log`，并先删除本机用户名、项目名等隐私信息。
