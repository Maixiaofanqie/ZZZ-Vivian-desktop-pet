# 视觉与交互规范

本文记录 v1.0 的视觉令牌、尺寸、气泡规则与交互动效。实现以 `src/renderer/styles.css` 与相关组件为准。

## 1. 视觉基调

优雅、安静、带一点世纪末的浪漫——像窗台上收起的一把黑伞，边缘镶着旧金色。
- **关键词**：暮紫 / 旧金 / 酒红；细线、衬线标题、留白。
- **情绪**：克制的陪伴感，不是喧闹的吉祥物。
- **界面基调**：暮紫浅色。奶油紫底、紫色主色、金色线条、酒红点睛；深色只保留在形象、图标与必要的强调色中。
- **禁忌**：高饱和霓虹、夸张动效、堆满屏的浮层、猫娘口癖。

## 2. 色彩令牌

| Token              | 色值                    | 用途                   |
| ------------------ | ----------------------- | ---------------------- |
| `--bg`             | `#f3eef8`               | 暮紫浅色底             |
| `--bg-soft`        | `#fbf8ff`               | 卡片/面板底            |
| `--primary`        | `#6b4c9a`               | 主紫、主控件           |
| `--primary-strong` | `#4e3574`               | 标题、选中态           |
| `--gold`           | `#8f6530`               | 可读金色文字、次级强调 |
| `--gold-bright`    | `#a87c3f`               | 装饰金线、眉题         |
| `--wine`           | `#a34f63`               | 危险、酒红点睛         |
| `--text`           | `#2b2235`               | 主文本                 |
| `--muted`          | `#6d637c`               | 次要文本               |
| `--line`           | `rgba(107,76,154,0.18)` | 边框/分隔线            |

气泡、设置与功能面板统一使用以上令牌，不在组件里散落硬编码颜色。正文对比度需达到 WCAG AA；亮金只作装饰，小字用 `--gold`。

## 3. 字体

| 用途               | 字体栈                                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| 标题 / 气泡 / 引语 | `"Noto Serif SC", "Source Han Serif SC", "SimSun", serif`                    |
| 界面 / 正文 / 数字 | `"Segoe UI Variable Text", "Microsoft YaHei UI", "Noto Sans SC", sans-serif` |
- Noto Serif SC 以 SIL OFL 1.1 随应用分发（`assets/fonts/NotoSerifSC-VF.ttf`）；正文使用系统 UI 字体，不随包分发。
- 标题字距 0.08–0.16em；中文标题不使用 0.2em 以上字距。
- 不使用外部网络字体，保证离线可用。

## 4. 尺寸与形状

| 元素     | 规格                                              |
| -------- | ------------------------------------------------- |
| 控件圆角 | 8px                                               |
| 卡片圆角 | 12px                                              |
| 卡片边框 | 1px `var(--line)`                                 |
| 气泡圆角 | 14px                                              |
| 气泡窗口 | 304×132 DIP                                       |
| 气泡字号 | 14px，行高 1.75；最多三行                         |
| 设置窗口 | 520×620，最小 480×540，可缩放；内容超出时内部滚动 |
| 功能面板 | 880×620，最小 720×500                             |
| 宠物窗口 | 320×320 DIP；形象可见底边对齐窗口底部             |

宠物没有独立的地面阴影窗口；悬停光晕由画布与 CSS 效果提供。源码构建没有角色图时窗口为空；有形象时按 320×320 等比缩放并底部对齐。

## 5. 形象呈现

- 形象为单张静态透明图，官方安装版包含 7 张表情；不做行走、睡眠或逐帧动画。
- 源码仓库不包含角色美术，宠物窗口保持空白（透明、不拦截点击）；设置页提示如何添加本地形象。
- 官方安装版的 7 张图对应标签：大笑 / 无语 / 委屈 / 思考 / 嫌弃 / 开摆 / wink。
- 图片四周保留透明边距；绘制时把 alpha 可见底部对齐到窗口底部，去掉脚下透明边距造成的浮空感。
- 默认位置与「重置位置」均为右侧、底部贴合工作区（距右 32px，底部不留空）。
- 命中面罩从合成后的画布降采样生成；气泡锚点使用对齐后的可见顶部。

## 6. 气泡规则

1. 同时最多 **1 条**气泡；新台词**抢占**旧气泡，不排队、不叠加。
2. 默认展示 4–6 秒；长台词按字符数延长，上限 12 秒。
3. **逐字淡入**：每字错开 40ms、淡入 140ms；已出现的字保持，整句最后随气泡淡出。气泡本身不接收鼠标；淡入中点击宠物立即显示全文，文字完整后再点击才抢占下一句。
4. 消失前淡出约 **180ms**（轻微下移 4px），主进程在淡出结束后再隐藏气泡窗口。
5. 位置跟随宠物，优先上方；靠屏幕边缘时自动翻转，不越界。
6. **垂直锚点使用形象的 alpha 可见边界**，不按窗口透明边缘计算；气泡窗口内部按上下贴边对齐。
7. 气泡不遮挡宠物本体；尾巴指向形象头顶。
8. 每次启动、每个时段第一次点击显示该时段问候；问候不参与普通随机。
9. 定时主动问候默认关闭；开启后 30–60 分钟一次，夜间也可触发；隐藏、拖拽、已有气泡时跳过。

## 7. 交互矩阵

| 操作         | 期望反馈                                                                   |
| ------------ | -------------------------------------------------------------------------- |
| 悬停         | 轻微放大 + 亮度略升，无台词                                                |
| 单击         | Q 弹缩放 + 逐字淡入气泡 + 记录互动；淡入中点击补全全文                     |
| 双击         | 循环模式且有多个形象时切换形象；固定模式不切换；统一双击判定，不弹两条气泡 |
| 右键         | 菜单：番茄钟（若开启）/ 功能面板 / 设置 / 隐藏 / 退出                      |
| 拖拽         | 跟手移动；松开后下落到工作区底部并轻弹一次                                 |
| 长时间无操作 | 无自主漫步；可选的定时主动问候（默认关闭）                                 |

**冷却与防刷**：快速连点只保留最新一条气泡，不做 3 秒冷却（选择「抢占」）；没有好感度数值或等级。

### 7.1 功能面板

- 入口：宠物右键菜单「功能面板」；不设托盘入口。
- 形态：普通窗口，左侧功能列表、右侧内容区；页面由已启用模块贡献。
- 项目条目显示：文件夹名、最后活跃时间、会话数、「在 VSCode 中打开」按钮；渲染层不接触完整路径。
- 主动台词可提及近期项目名，但不显示对话内容或代码。

### 7.2 静态形象与切换

- 形象为 Q 版半身/头像，单张静态透明图；可选呼吸/轻微摇摆，不做眨眼、行走或循环帧动画。
- 点击反馈：按下 `scale(0.94)`，松开动画 `1.06 → 0.98 → 1`（约 260ms）；图片四周保留透明边距，避免缩放时裁边。
- 默认模式「双击切换」；设置页可关闭切换，改为固定自选。源码构建没有形象图时开关禁用。
- 拖拽松手后：以重力下落到当前显示器工作区底部，触地后轻弹一次（约 15px），同时播放脚底挤压动画；最终停在底部。

### 7.3 待机微动效

- 呼吸：以脚底为原点 `scale(1.000 ↔ 1.035)`，周期 3.2s，`ease-in-out`。
- 摇摆：以脚底为原点 `skewX(±1.4deg)`，周期 4.8s；不用 `rotate`，让底边保持不动，避免被窗口底部裁切产生锯齿。
- 两层变换嵌在点击/落地动画外层，互不覆盖。
- 拖拽期间暂停；松手落地后恢复。
- 设置页「待机微动效」开关，默认开启；关闭后完全静态。
- `prefers-reduced-motion: reduce` 时关闭。
- 不为微动效逐帧更新命中面罩或气泡锚点（位移约 2px，小于命中网格粒度）。

### 7.4 单击、悬停与右键

- 单击判定：双击窗口 280ms，单击延迟 300ms；循环/固定模式统一；固定模式双击不会弹两条气泡。
- 悬停：由主进程命中检测驱动，透明区域不触发；轻微放大 1.02 + 亮度 1.04。
- 右键菜单：番茄钟（若开启）/ 功能面板 / 设置 / 隐藏 / 退出；使用原生菜单。
- 气泡：逐字淡入；淡入中点击宠物补全；新台词抢占旧气泡。
- 定时问候：默认关闭，30–60 分钟，夜间也可触发；隐藏、拖拽、已有气泡时跳过。

### 7.5 作息与数据设置

- 设置页提供「久坐提醒」「深夜催睡」「彩蛋」三个开关，默认开启；关闭后立即停止对应行为，重启保持。
- 久坐文案：连续在电脑前 60 分钟时提醒起身；休息 5 分钟重置。
- 催睡文案：23:30–05:00 轻声提醒休息，一晚最多两次。
- 「数据备份」提供「导出」「导入」两个文字按钮（金色描边）；导入成功后在该卡片内显示一行提示，失败则在页脚显示错误。
- 提醒与彩蛋沿用现有白色气泡样式，不新增窗口或视觉层。

## 8. 动效规范

- 可关闭的待机呼吸/摇摆；不做眨眼、行走、睡眠等动作。点击 Q 弹、拖拽跟手、落地挤压与界面过渡保留。
- 气泡：卡片淡入约 220ms；文字逐字错开 40ms、淡入 140ms；消失前整体淡出约 180ms。
- 落地：重力下落至工作区底部，首次触地回弹约 15px，挤压动画约 320ms。
- 拖拽：主进程 8ms 跟随 + 渲染层 resize 防抖，避免移动窗口时重建画布。
- 目标 60 FPS；低于 45 FPS 视为性能问题；拖拽时窗口位置更新最大间隔应小于 20ms。
- 不使用闪烁、突然放大、剧烈抖动。
- 尊重 `prefers-reduced-motion`：关闭非必要动画，保留淡入淡出。

## 9. 文案语气

- 角色台词中称玩家为「法厄同大人」；语气柔和、偶尔崇拜，害羞时语速快。
- 日常：优雅、简洁，不用网络烂梗堆砌。
- 提醒类：用「预知」包装，例如「我预见到……三分钟后，您会忘记喝水。」
- 不使用「喵」「nya」等猫娘口癖。
- 技术错误不对用户念台词，使用简短中性提示 + 日志。
- 设置页、错误提示与文档使用中性、直接的表达，不把角色口吻带进技术文案。
